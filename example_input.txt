# ---- 版面定义（名称 容量）----
版面 头版 18
版面 副刊 10
版面 广告版 8

# ---- 稿件定义（编号 篇幅 优先级 类型）----
稿件 N1 8 高 新闻
稿件 N2 6 中 新闻
稿件 N3 5 低 新闻
稿件 A1 6 中 广告
稿件 A2 4 高 广告
稿件 BIG 30 高 新闻

# ---- 排版流 ----
放 头版 N2        # 头版已用6
放 头版 A1        # 头版已用12
放 头版 N1        # 剩6放不下8：挤位阶最低的A1(中/广告)，A1级联到副刊
放 副刊 N3        # 副刊剩4放不下5，N3比A1位阶低不能挤 -> 超出1，报错
放 头版 N1        # 重复放稿 -> 报错
放 头版 BIG       # 挤光低位阶仍差 -> 报错，超出量
放 广告版 N3      # N3 改投广告版（剩3）
放 广告版 A2      # A2(高/广告)挤占N3(低/新闻)，各备用版面均满 -> N3回待排
撤 广告版 A2      # 撤广告 -> N3级联回占广告版
撤 头版 N2        # 释放头版6位 -> A1从副刊级联回到原版面头版
放 财经版 N2      # 版面不存在 -> 报错
撤 头版 X99       # 稿件不存在 -> 报错
撤 头版 N3        # N3在广告版，不在头版 -> 报错
放 副刊 A1        # A1已排在头版 -> 重复放稿报错
撤 头版 BIG       # BIG是待排状态 -> 报错
